1. API Lấy danh sách Models (REST API)
Mặc dù Google Gen AI SDK không có hàm gọi trực tiếp lấy danh sách, bạn có thể dễ dàng lấy toàn bộ danh sách model (bao gồm cả các model TTS mới nhất) thông qua REST API tiêu chuẩn của Google.

Bạn có thể gọi endpoint này trực tiếp từ trình duyệt, Postman hoặc dùng fetch:

JavaScript

// Thay YOUR_API_KEY bằng API Key thật của bạn
const apiKey = process.env.GEMINI_API_KEY;
const url = `https://generativelanguage.googleapis.com/v1beta/models?key=${apiKey}`;

fetch(url)
  .then(response => response.json())
  .then(data => {
    // Lọc ra các model có hỗ trợ TTS hoặc Audio
    const ttsModels = data.models.filter(model => 
      model.name.includes('tts') || model.supportedGenerationMethods.includes('generateAudio')
    );
    console.log(ttsModels);
  });


  Lưu ý: API này trả về thông tin các mô hình (ví dụ: models/gemini-3.1-flash-tts-preview), nhưng không trả về danh sách các giọng đọc (Aoede, Puck, v.v.). Danh sách giọng đọc bạn vẫn quản lý thủ công như ở bước trước.

2. Code Next.js API Route sử dụng Gemini TTS
Đây là mã nguồn chuẩn cho file API Route trong Next.js App Router (ví dụ đặt tại src/app/api/tts/gemini/route.ts). Code này sử dụng model gemini-3.1-flash-tts-preview mới nhất.

TypeScript
// src/app/api/tts/gemini/route.ts
import { NextResponse } from 'next/server';
import { GoogleGenAI } from '@google/generative-ai';

// Khởi tạo SDK với API Key từ biến môi trường
const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY as string });

export async function POST(request: Request) {
  try {
    const body = await request.json();
    const { text, voiceName = 'Aoede' } = body;

    if (!text) {
      return NextResponse.json({ error: 'Vui lòng cung cấp văn bản cần đọc.' }, { status: 400 });
    }

    // Khởi tạo model TTS của Gemini
    const model = ai.getGenerativeModel({ 
      model: 'gemini-3.1-flash-tts-preview' 
    });

    // Cấu hình payload gửi lên Gemini
    const response = await model.generateContent({
      contents: [
        { 
          role: 'user', 
          parts: [{ text: text }] 
        }
      ],
      config: {
        // Yêu cầu mô hình trả về dữ liệu Âm thanh thay vì văn bản
        responseModalities: ['AUDIO'],
        speechConfig: {
          voiceConfig: {
            prebuiltVoiceConfig: {
              voiceName: voiceName, // Các tuỳ chọn: 'Aoede', 'Charon', 'Fenrir', 'Kore', 'Puck'
            }
          }
        }
      }
    });

    // Bóc tách dữ liệu base64 âm thanh từ luồng trả về
    let audioBase64 = '';
    const candidate = response.candidates?.[0];
    
    if (candidate?.content?.parts) {
      for (const part of candidate.content.parts) {
        if (part.inlineData && part.inlineData.data) {
          audioBase64 = part.inlineData.data;
          break;
        }
      }
    }

    if (!audioBase64) {
      throw new Error('Google API không trả về dữ liệu âm thanh hợp lệ.');
    }

    // Chuyển đổi base64 thành Buffer
    const audioBuffer = Buffer.from(audioBase64, 'base64');

    // Trả về luồng âm thanh trực tiếp cho Frontend (định dạng WAV)
    return new NextResponse(audioBuffer, {
      status: 200,
      headers: {
        'Content-Type': 'audio/wav',
        'Content-Length': audioBuffer.length.toString(),
        'Cache-Control': 'no-store, max-age=0',
      },
    });

  } catch (error: any) {
    console.error('Lỗi Gemini TTS API:', error);
    return NextResponse.json(
      { error: error.message || 'Đã xảy ra lỗi máy chủ nội bộ' }, 
      { status: 500 }
    );
  }
}
3. Cách gọi API từ giao diện Client (Frontend)
Ở phía UI, bạn có thể tạo một hàm để gọi API này và phát âm thanh ngay lập tức bằng HTML5 Audio.

TypeScript
// src/components/TTSPlayer.tsx
'use client';

import { useState } from 'react';

export default function TTSPlayer() {
  const [text, setText] = useState('');
  const [isLoading, setIsLoading] = useState(false);

  const handlePlayTTS = async () => {
    if (!text) return;
    setIsLoading(true);

    try {
      const response = await fetch('/api/tts/gemini', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          text: text,
          voiceName: 'Puck' // Truyền giọng đọc mong muốn vào đây
        }),
      });

      if (!response.ok) throw new Error('Lỗi khi tạo giọng nói');

      // Nhận luồng nhị phân (Blob) từ backend
      const audioBlob = await response.blob();
      
      // Tạo một URL tạm thời cho file âm thanh và phát nó
      const audioUrl = URL.createObjectURL(audioBlob);
      const audio = new Audio(audioUrl);
      
      audio.play();
      
    } catch (error) {
      console.error(error);
      alert('Tạo âm thanh thất bại!');
    } finally {
      setIsLoading(false);
    }
  };

  return (
    <div className="p-4 space-y-4">
      <textarea 
        className="w-full p-2 border rounded"
        rows={4}
        value={text}
        onChange={(e) => setText(e.target.value)}
        placeholder="Nhập văn bản cần đọc..."
      />
      <button 
        onClick={handlePlayTTS} 
        disabled={isLoading}
        className="px-4 py-2 text-white bg-blue-600 rounded disabled:bg-gray-400"
      >
        {isLoading ? 'Đang xử lý...' : 'Phát âm thanh'}
      </button>
    </div>
  );
}
